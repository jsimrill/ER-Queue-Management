#Purpose of this simulation
The purpose of this simulation is to try and identify the bottlenecks associated with wait times in ER Waiting rooms. Patients are often upset when they are met with long waiting times in
the ER, and in order to solve this issue, I will employ different strategies in order to test which minimizes the wait time the most. The three strategies that I am employing are: FIFO,
Priority Queue, and Staffing Increases. FIFO is a strategy that treats each patient as they arrive. Priority queue assigns each patient a severity and the patients with the highest severity
are treated first. Lastly, staffing increases will just add more doctors, nurses, and beds.

#How to Run the Simulation:
  1. Load the RScript into RStudio.
  2. You can see the individual strategy data by typing the results_(strategyName) into the console.
  3. If you want to Run the simulation, select the code body and click on the Run button.
     This will run the simulation and generate the plots/graphs associated.
  4. If you wish to alter the input data, you can change the arrival speed, number of patients, and simulation length in the code.
